# Telegram Mini App — магазин 3D-печати (скелет)

Скелет фронтенда для Telegram Mini App: каталог-заглушка, карточка товара, форма **«Свой вариант»** (материал, цвет, размер, количество, STL, комментарий), корзина и экран успеха. Бэкенда, оплаты и доставки пока нет — заказ собирается в JSON локально.

Интерфейс на русском. Город/логика под Москву/РФ (валюта ₽).

## Что внутри

| Экран | Описание |
|--------|----------|
| Каталог | 5 демо-товаров (название, цена, описание, цвет-плейсхолдер) |
| Товар | Детали + «В корзину» |
| Свой вариант | Форма параметров + загрузка STL (только имя файла) |
| Корзина | Сводка, удаление позиций |
| Успех | Превью JSON заказа |

Telegram WebApp: скрипт `telegram-web-app.js`, `ready()` / `expand()`, тема из `themeParams`, **MainButton** «Оформить заказ» (вне Telegram — кнопка внизу экрана).

## Быстрый старт (локальный превью)

```bash
cd /workspace/tg-3d-shop-miniapp   # или путь к проекту у вас
npm install
npm run dev
```

Откройте URL из терминала (обычно `http://localhost:5173`). В браузере приложение работает без Telegram; MainButton появится только внутри клиента Telegram.

Сборка и превью production-сборки:

```bash
npm run build
npm run preview
```

`preview` поднимает статику на порту **4173** (см. `vite.config.js`).

## Как подключить к боту (BotFather)

Telegram Mini App открывается только по **публичному HTTPS**. Локальный `localhost` бот не откроет — нужен туннель или хостинг.

### 1. Получите публичный HTTPS-URL

Варианты для теста:

- **ngrok**: `ngrok http 5173` (при `npm run dev`) или `ngrok http 4173` (при `npm run preview`)
- **Cloudflare Tunnel**, **localtunnel**, **serveo** — аналогично
- Постоянно: Vercel / Netlify / Cloudflare Pages / любой статический хостинг после `npm run build` (папка `dist/`)

Скопируйте выданный `https://….ngrok-free.app` (или ваш домен).

### 2. Привяжите Web App к боту

**Вариант A — Menu Button**

1. Откройте [@BotFather](https://t.me/BotFather)
2. `/mybots` → ваш бот → **Bot Settings** → **Menu Button** → **Configure menu button**
3. Укажите текст кнопки (например, `Магазин`) и HTTPS-URL Mini App

**Вариант B — отдельное Mini App**

1. BotFather → `/newapp` (или в настройках бота **Configure Mini App**)
2. Выберите бота, название, описание, фото (по желанию)
3. Укажите Web App URL (тот же HTTPS)

**Вариант C — кнопка в сообщении** (нужен код бота)

Отправьте пользователю кнопку `web_app` с вашим URL (через Bot API / библиотеку). Для скелета достаточно Menu Button.

### 3. Проверка

Откройте бота в Telegram → нажмите кнопку меню / Mini App. Должны открыться каталог и формы. MainButton «Оформить заказ» виден на экране корзины с товарами.

## Что заполнить / доделать позже

1. **Реальные товары** — заменить массив `PRODUCTS` в `src/data.js` (или подгрузить с API).
2. **Картинки** — вместо цветных плейсхолдеров и emoji: URL изображений / CDN.
3. **Бэкенд** — принимать заказ (webhook бота или REST): сейчас JSON только в `localStorage`/консоли и на экране успеха.
4. **Отправка в Telegram** — после оформления слать заказ боту (`sendData` / ваш API), писать менеджеру в чат.
5. **Оплата** — Telegram Payments / ЮKassa / CloudPayments и т.п.
6. **Доставка** — самовывоз Москва, курьер, СДЭК/Boxberry; карта/адрес; оплата наличными при получении.
7. **Загрузка STL** — сейчас хранится только **имя файла**; нужен upload на сервер/S3 и проверка формата.
8. **Цены «Свой вариант»** — формула в `estimateCustomPrice` — заглушка; считать после анализа модели.
