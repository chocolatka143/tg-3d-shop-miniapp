# Деплой Mini App на Timeweb (Year / классический хостинг) через ZIP

Архив: `/workspace/tg-3d-shop-miniapp-dist.zip`  
Внутри: `index.html` в корне (не вложенная папка `dist/`).

## Важно про баланс

Баланс **Timeweb Cloud / App Platform** и оплата **классического виртуального хостинга Year** могут быть разными продуктами.  
Если в панели нет файлового менеджера / `public_html` — закажи/активируй **виртуальный хостинг Year** в панели Timeweb (не путать с Cloud Apps).

## Шаги

1. **Хостинг Year**  
   В панели Timeweb: заказать или активировать виртуальный хостинг Year (если ещё не активен). Дождись появления сайта и доступа к файлам.

2. **Файловый менеджер**  
   Открой сайт → **Файловый менеджер** (или FTP). Папка сайта обычно: `public_html` (иногда `www` / `htdocs`).

3. **Загрузить ZIP**  
   Загрузи `tg-3d-shop-miniapp-dist.zip` **в корень** `public_html` (рядом с будущим `index.html`, не внутрь лишней вложенной папки).

4. **Распаковать**  
   В файловом менеджере: «Извлечь» / Unzip архив.  
   Проверь: в `public_html` лежит `index.html`, рядом папка `assets/`.  
   Старые файлы-заглушки Timeweb (типа `index.php` / демо) можно удалить или заменить, чтобы открывалась наша витрина.  
   Сам `.zip` после распаковки можно удалить.

5. **Бесплатный SSL (HTTPS)**  
   В панели сайта включи **бесплатный SSL** (Let's Encrypt / «SSL-сертификат»). Дождись статуса «выдан».  
   Mini App в Telegram требует **HTTPS**.

6. **URL для BotFather**  
   Скопируй адрес вида `https://твой-домен.ru/` (или техдомен Timeweb, если домен свой ещё не привязан).  
   В [@BotFather](https://t.me/BotFather): бот → **Bot Settings** → **Menu Button** → указать этот HTTPS-URL.

7. **Проверка**  
   Открой URL в браузере — должна открыться витрина.  
   В Telegram: кнопка меню бота → Mini App.

## Обновление позже

Снова: `npm run build` → новый ZIP из содержимого `dist` → залить и распаковать поверх (или заменить файлы).  
Когда понадобится автодеплой из Git — можно перейти на Timeweb Apps / GitHub.
